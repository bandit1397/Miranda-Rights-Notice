# 다국어 권리고지 (Miranda & Rights Notice)

외국인을 현장에서 체포하거나 임의동행·영사 통보 절차를 밟을 때, 경찰관이 **자신의 휴대폰으로** 해당 외국어 음성과 번역문을 보여 주며 고지할 수 있는 웹앱입니다.

- **상황 3가지**: 현장 미란다(현행범 체포) · 임의동행 · 영사기관 통보
- **19개 언어**: 중국어, 베트남어, 태국어, 우즈베크어, 영어, 러시아어, 몽골어, 네팔어, 인도네시아어, 필리핀어, 캄보디아어, 미얀마어, 카자흐어, 싱할라어, 벵골어, 일본어, 스페인어, 프랑스어, 아랍어
- **죄명 11종**: 절도, 강도, 폭행, 상해, 사기, 마약류관리법 위반, 음주운전, 강제추행, 출입국관리법 위반, 공무집행방해, 범죄(미특정)
- 임의동행은 경찰관 정보(소속·이름, 기기에 저장)와 **동행 목적(죄명)·이유·장소**를 골라 고지합니다. 소속·이름·장소명은 화면에 한글과 로마자로 표시하고, 음성은 "소속과 이름은 화면과 신분증에 표시되어 있습니다"라는 공통 문장으로 읽습니다.
- 임의동행·영사 통보는 상대방이 자기 언어로 된 **예/아니오 버튼**을 누르면, 응답과 시각이 한국어로 표시됩니다.
- 중국 국적자는 한중 영사협정에 따른 **의무 통보** 안내로 전환할 수 있습니다.

## 사용법

1. 휴대폰 브라우저로 사이트를 엽니다. 메뉴의 "홈 화면에 추가"를 누르면 앱처럼 설치됩니다.
2. 처음 한 번 **오프라인 저장**을 누르면 전체 음성(약 29MB)이 저장되어, 이후에는 인터넷 없이 동작합니다.
3. 상황 → 언어 → (미란다일 때) 죄명, (임의동행일 때) 경찰관 정보·동행 목적·이유·장소를 고르고 **고지 화면 열기**를 누릅니다. 이어서 **▶ 재생**을 누릅니다.
4. 휴대폰 화면을 상대방에게 보여 주세요. 외국어 문장이 크게 표시되고, 재생 중인 문단이 강조됩니다. 한국어 원문은 하단에서 확인합니다.

## 음성(TTS)에 대해

음성은 실시간 합성이 아니라 **Microsoft Azure 뉴럴 음성으로 미리 만든 MP3**입니다. 그래서 기기 종류와 관계없이 원어민에 가까운 같은 음질로 재생되고, 현장에서 인터넷이 필요 없습니다. MP3가 없거나 재생에 실패하면 기기 내장 TTS로 대신 읽습니다.

- 지금은 [`edge-tts`](https://github.com/rany2/edge-tts)로 생성했습니다. 무료이고 가입이 필요 없지만 **비공식 도구**입니다.
- 기관에서 정식으로 운영할 때는 같은 음성을 쓰는 **Azure Speech 무료 등급(F0, 월 50만 자)**으로 바꿔 생성하는 것을 권장합니다. 전체 고지문은 약 3만 자여서 무료 한도로 충분하고, 음성 이름(`*-Neural`)이 같아 음질도 같습니다.

### 고지문 수정 → 음성 다시 만들기

```bash
pip install edge-tts
python tools/generate_audio.py          # 바뀐 문장만 다시 생성
python tools/generate_audio.py --lang vi  # 특정 언어만
```

- 고지문은 `data/lang/<언어코드>.json`, 죄명 목록은 `data/crimes.json`, 언어 목록과 음성 지정은 `data/languages.json`에 있습니다.
- 앱 파일(`index.html`, `app.js`, `style.css`)을 수정했다면 `sw.js`의 `SHELL` 버전을 올려 주세요.

## ⚠️ 번역 검수

한국어 원문(`ko.json`)과 영어 고지문 4개 문장은 기준 문구입니다. **나머지 외국어 번역은 검수 전 초안**이며, 앱 화면에도 "번역 검수 전 초안"이라고 표시됩니다. 정식으로 사용하기 전에 경찰청 공식 외국어 고지문이나 원어민 감수로 확인하세요. 확인이 끝난 언어는 해당 JSON의 `"reviewed": true`로 바꾸면 표시가 사라집니다.

## 법적 근거 (참고)

- 체포 시 고지: 형사소송법 제200조의5, 제213조의2 (범죄사실 요지, 체포 이유, 변호인 선임권, 변명 기회), 제244조의3 (진술거부권), 제214조의2 (체포·구속적부심)
- 임의동행: 경찰관 직무집행법 제3조 — 제2항(동행 이유: 그 장소에서 질문하는 것이 본인에게 불리하거나 교통에 방해), 제4항(신분 표시, 소속·성명, 목적·이유 설명), 제5항(동행 장소, 가족 등에게 알리거나 연락할 기회, 변호인의 도움을 받을 권리)
- 영사 통보: 영사관계에 관한 비엔나협약 제36조, 대한민국과 중화인민공화국 간의 영사협정 (본인 의사와 관계없는 통보)

다른 나라와의 양자 협정에 따른 의무 통보 대상인지는 소속 기관의 지침을 확인하세요.
